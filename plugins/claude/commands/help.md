---
description: Show Tersio's Claude Code commands and modes
---

Reply with this table, then stop:

| Command | What it does |
|---|---|
| `/tersio` | Show the active combo line |
| `/tersio:combo <off\|lite\|balanced\|max>` | Set the combo preset |
| `/tersio:caveman <level>` | Set Caveman |
| `/tersio:ponytail <level>` | Set Ponytail |
| `/tersio:pstack <on\|off>` | Set pstack |
| `/tersio:rtk <on\|off>` | Enable or disable the RTK Bash hook |
| `/tersio:headroom <on\|off>` | Set the Headroom preference |
| `/tersio:update` | Update Tersio and refresh this plugin |
| `/tersio:help` | Show this table |

Modes stay on until you turn them off with the same command or say `normal mode`.
