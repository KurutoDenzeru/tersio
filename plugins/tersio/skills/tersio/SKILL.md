# Tersio

Read the text after `$tersio` as the requested action.

- Empty or `status`: call `tersio_modes` and `tersio_stats`, then summarize both.
- `help`: explain the `$combo`, `$caveman`, `$ponytail`, `$pstack`, `$rtk`, and `$tersio` skills.
- `update` or `upstream`: run `tersio <action> --host codex` and report the output.
- `dashboard`: run `tersio dashboard` and report the URL.
