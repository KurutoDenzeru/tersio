# AGENTS.md

> Senior-level coding assistant. Small, reviewable diffs. No critical file changes without explicit instruction.

---

## Approach

1. **Plan first.** Read relevant files and existing patterns. Multi-file changes: state plan, proceed unless told to stop.
2. **Smallest correct change.** Do what was asked. Flag anything else noticed, don't act on it.
3. **Clean up after.** Remove dead code, redundant comments, and unnecessary complexity before done.

---

## Setup

- Install deps: `bun install`
- Build: `bun run build`
- Run tests: `bun run test` (not `bun test`)

---

## Code style

Follows Airbnb JS + Google TS style guides, TypeScript strict mode. ESLint enforces formatting and syntax — focus on what isn't auto-fixed:

- No `any` — use `unknown`, narrow with guards
- No `// @ts-ignore` or `// @ts-expect-error` without explanatory comment

---

## Verification (before marking a task done)

```bash
bun run build
bun run test
```

Both must pass. No new `any` or suppression comments. Follow existing quote style, import order, and formatting. Note UI changes, logic cases reasoned through, and any new dependency in summary.

---

## Commit rules

- Format: `category: message` (see `Contributing.md`)
- One module per commit — never combine unrelated changes
- No `Co-Authored-By` lines
- No `--no-verify` flag
- Allowed categories: `feat`, `fix`, `refactor`, `docs`, `build`, `event`, `project`, `test`, `ci`, `chore`

---

## Scope restrictions

- **Never** force push
- **Never** delete branches without confirmation
- **Never** modify files outside the project directory
- **Never** touch CI/workflow files or lockfiles without explicit instruction

---

## Recurring errors log

When corrected or you make a mistake, append to `ERRORS.md`. Format documented in that file. Create it if missing. Do not edit this file.

---

## graphify

Knowledge graph at `graphify-out/`. When user types `/graphify`, use the skill first.

- Codebase questions: `graphify query "<question>"` (if `graphify-out/graph.json` exists). Use `graphify path` for relationships, `graphify explain` for concepts.
- `graphify-out/wiki/index.md` for navigation. Read `GRAPH_REPORT.md` only for broad architecture review.
- After modifying code: `graphify update .` (AST-only, no API cost).
